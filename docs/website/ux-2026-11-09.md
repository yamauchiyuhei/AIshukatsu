# AI就活 Web UI/UX 改善（2026-11-09）

## 変更した体験

- トップ・マガジンの共通ナビゲーション、テーマ切り替え、はじめ方の案内。
- スマートフォンには記事閲覧とPCでの開始を案内。PCにはWeb版と対応するOSの配布案内を表示。
- PC画面例はスマホで重要部分を拡大表示し、ネイティブの拡大ダイアログから全体も確認可能。
- 技術用語中心だった説明を、メモ・締切・選考管理の具体的な用途に変更。
- 企業の業界フィルター、企業名・記事名順、英語名・略称・旧社名の検索を拡張。
- 一覧カードで企業名と記事のテーマを分離。スマホの一覧は画像とタイトルを横に並べる。
- 記事の導入文を維持し、先に確認できる3項目と章へのリンクを追加。
- スマホの章ナビゲーション、前回の章からの再開、あとで読む、閲覧履歴、3社の比較候補。
- 記事からWebアプリへ企業名・記事URLを引き継ぎ、任意の操作でメモを作成。同名ファイルは保持して開く。
- 公開日・更新日の方針、参考資料と誤りの連絡先を明示。

## データと制約

原稿2,006本の本文・参考資料・公開日・更新日・表紙は変更しない。既存のサイトマップを維持する。下書きの公開とnoindexの解除は行わない。

企業記事1,000本のうち、既存の企業分類から604社を分類できる。残る396社は推測で分類せず「未分類」とする。記事概要の公開メタデータに `companyIndustry` を加えるが、本文原稿は変更しない。

あとで読むは60件、履歴は30件、比較候補は3社。`aishukatsu-reading-list-v1` に必要な公開記事情報だけを保存し、このブラウザ内だけで利用する。保存が拒否されても記事は読める。各一覧から消去可能。

記事の「メモを作る」は `/app/?article=<公開記事slug>` に移動する。ログイン・保存先設定を経ても同じURLで引き継ぐ。公開記事のスキーマを検証し、「メモを作成・開く」を押した場合だけ `記事メモ/<slug>.md` を作成する。ユーザーが既存メモに追記した内容を上書きしない。

今回の配信はWebサイトとWebアプリ。Mac・Windowsの配布バイナリ更新は含まない。
