# 記事からデスクトップの研究メモへ

対応開始: v0.2.20。Mac Universal（Apple Silicon / Intel）、Windows x64 / ARM64。

記事の主ボタンは `aisyuukatsu://research?article=<公開記事slug>` を開く。OSのアプリ起動確認の後、アプリ側で公開記事の企業名・記事URL・保存先を確認して「メモを作成・開く」を押す。

- 起動済みの場合は既存ウィンドウに受け渡す。新規起動はdeep-linkプラグインのgetCurrentから復元する。
- ログイン・初期設定を経ても、作成待ちの記事を保持する。重複URLをまとめ、最大10件を順に扱う。24時間経過した依頼は破棄する。
- `research` 以外のホスト、任意URL、ファイルパス、重複・未知のパラメーターは受け付けない。Google認証用のauth-callbackには影響させない。
- 記事本文はRust側で公式サイトの公開記事エンドポイントから取得する。転送先追従なし、HTTPSのみ、15秒の上限、公開状態とslugの一致を確認し、さらにフロントエンドで記事スキーマを検証する。
- ファイル作成はアプリ側のボタンを押した場合のみ。選択済み保存先の `記事メモ/<slug>.md` に企業名・出典URL・書き込み用の見出しを保存する。同名ファイルは保持して開く。
- 未インストール・旧版ではダウンロード案内を表示する。ブラウザからインストール有無を断定したり、勝手にダウンロードへ転送したりしない。
- スマートフォンではPC用アプリの入手方法へ案内する。Web版のメモ作成は補助リンクとして保持する。

検証: `npm run test:research`、`npm run test:app`、`npm run test:updater`、`cargo test --manifest-path src-tauri/Cargo.toml --locked`。公開記事・サイトマップ・リンクの既存検証も実施する。

Mac・Windowsの署名付き成果物を下書きリリースに集め、全ての更新署名とバージョンを検証してから配信する。Webの起動ボタンは対応版の配信後に公開する。
