# AI就活の案内方針

2026-11-09のユーザー指定により、主に案内する製品はMac・Windowsのデスクトップアプリとする。

- 共通ヘッダー、トップの最初のボタン、はじめ方、記事の主ボタンはアプリのダウンロード案内へ進める。
- Mac・Windowsを判別できる場合は、対応する版を優先表示する。
- スマートフォンにはPC用アプリの入手方法と、PCで開ける案内URLを提示する。スマートフォンにデスクトップ版をインストールできる案内はしない。
- Web版は補助的な試用の選択肢として残す。ダウンロード欄では折りたたみ、記事ではテキストリンクで案内する。
- v0.2.20以降の記事からの研究メモ作成はデスクトップ版を主導線とし、Web版は補助として明示する。対応バージョンと未インストール時の案内を表示する。
- デスクトップ版を優先する変更によって、記事やWeb版の既存機能を削除しない。
